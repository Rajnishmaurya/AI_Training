# Event Enrollment Manager

A frontent application built using React.js and Vite.

## Technology Stack
- React.js
- Vite
- JavaScript
- React Router Dom
- CSS
- Browser localstorage


## Installation 

npm install 

Install React Router: npm install react-router-dom

## Run application 

npm run dev

## Features
1. Browse 6 events
2. Search events by title
3. Filter events by category
4. Register Attendies
5. Validate name and email
6. Prevent duplicate registrations
7. Manage available seats
8. View registrations
9. Cancel registrations
